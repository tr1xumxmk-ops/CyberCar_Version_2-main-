# References used for hardware notes

- Espressif Arduino-ESP32 Wi-Fi documentation (Soft-AP creates a Wi-Fi network that local devices can join; AP mode does not itself provide Internet access): https://docs.espressif.com/projects/arduino-esp32/en/latest/api/wifi.html
- STMicroelectronics L298 product page and datasheet (H-bridge, enable inputs, motor driver electrical behavior): https://www.st.com/en/motor-drivers/l298.html
- LOLIN S2 Mini pinout reference (cross-check physical GPIO labels against your actual board): https://www.espboards.dev/esp32/lolin-s2-mini/

Always check the documentation that came with the exact board/module revision you own; clone wiring and regulator jumpers can differ.

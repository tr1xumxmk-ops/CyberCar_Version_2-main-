# Images, faces, photos, logos and third-party assets

This project includes face-expression pictures provided by the project owner for the dashboard. Their original source and redistribution permissions have not been independently verified by the project packaging process.

- Do not assume the Apache software license or CERN open-hardware license changes the copyright status of photos or artwork.
- Before publishing a public repository, distributing the project to a school/team, using it in a product, or selling a board, make sure the person or organization with rights to each image has given permission for the intended use.
- For team-member portraits, obtain each person's permission for the intended public use and retain only the files needed for the interface.
- Keep a small `ASSET_CREDITS.md` record for every externally sourced image, icon, font or audio clip: filename, creator/owner, original source, license/permission, changes made and attribution requirement.
- If rights are unknown or unclear, replace the asset with original artwork, self-created SVG graphics or an explicitly licensed asset.

This note does not assert that any supplied image is infringing; it simply separates image rights from the software and hardware licenses.
